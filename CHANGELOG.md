# Changelog

## 1.0.0

First release, as the successor to BackImage.

- Full-window background, or separate backgrounds for the editor, the primary side bar, the secondary side bar and the panel.
- Image sources: files, folders (with rotation, random order and subfolders) and `https://` URLs.
- Opacity, fit, position and blur per area, with a cross-fade between images.
- Most changes apply without a restart.
- Import of BackImage settings, including cleanup of BackImage's patch and backup files.
- Export and import of settings as JSON.
- The patch is re-applied automatically after VS Code updates and is removed exactly, without full-file backups.
- English and Japanese UI.
